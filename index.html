Volyx Lens

Independent project

A macOS assistant that reads the screen you choose, listens to a microphone or meeting audio, runs OCR locally, retrieves relevant context, transcribes, and routes to several AI providers.

My work

Case 02Local RAG and evaluationVersioned evaluation

Local Review Intelligence

Independent project

A local review tool that loads whatever CSV you give it, maps the fields, and answers questions with citations you can open. Every citation is validated, and an answer gets one bounded repair attempt when a sentence isn’t supported.

My work
Built adaptable field mapping, stable record identity, recoverable vector indexes, citation validation, bounded repair, privacy-safe diagnostics and an installable CLI.
Evaluation result
Clean exact-commit 30-case benchmark: Semantic Recall@5 0.913 versus 0.770 for BM25; answer success and citation validity 0.880.

Stack Python · Ollama · Chroma · Streamlit · Typer

Case 03Temporal ML evaluationRolling-origin evaluation

Football Forecasting Lab

Independent project

A football forecasting pipeline that splits data chronologically into train, calibration and test windows, then freezes the test set. It uses calibrated XGBoost and Poisson models.

My work
Built the data pipeline, temporal features, model evaluation, FastAPI service and Streamlit interface, with dedicated workflows for live, retrospective and synthetic datasets.
Evaluation result
Across 1,140 rolling-origin test matches it gets 53.77% accuracy. The bookmaker benchmark for the same matches is 56.70%.

Stack Python · XGBoost · scikit-learn · FastAPI · Streamlit

      The Hidden Complexity of RAG

      Hashnode · Jul 2026

      A working RAG demo and a production RAG system are different problems. Parsing, chunking, hybrid retrieval, reranking, evaluation and security each fail on their own.

      A Million-Token Context Is Not Memory

      Hashnode · Aug 2026

      A bigger context window isn’t memory. Agent memory holds up when you decide what to admit, retrieve, consolidate, revise and forget.

      MCP Made Tools Connectable. It Did Not Make Them Understandable.

      Hashnode · Aug 2026

      MCP standardizes how models connect to tools. A small controlled experiment shows that the tool contract itself (names, schemas, side effects) still has to be designed on its own.

      The Handoff Problem: Why Multi-Model AI Pipelines Quietly Corrupt Good Research

      Hashnode · Jul 2026

      Evidence degrades when one model hands research to another. A claim-level contract keeps citations and scope intact across the handoff.

      The Two Boundaries Where Voice Agents Quietly Corrupt State

      Hashnode · Jul 2026

      Two places voice agents break, acoustic-to-transcript and propose-to-commit. A call can sound perfect and still commit the wrong backend state.
